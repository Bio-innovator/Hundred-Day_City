# 百日之城 · Hundred-Day City

简体中文 | [English](README.en.md)

一款像素风基地建造与多地图物流增量游戏。建造设施、铺设商路，在一百天内把文明备份送往月背。

在线试玩：https://bio-innovator.github.io/Hundred-Day_City/

## 背景

太阳风暴之后，地表文明在三十年内崩塌。你是唯一仍在运行的 AI 运算中心，被遗留在一座灰烬平原的地下机房里，唯一指令是「保存文明」。

你没有手脚，只能通过建造设施、铺设商路，把散落在废墟里的资源重新连成一张网。一百天后，日冕脉冲会再次扫过地表——在那之前，你必须把文明备份送抵月背。

## 前 5 分钟的操作建议

第一次进入游戏时，会跟随一套分步引导熟悉基本操作：放下太阳能板、放下废料场、把废钢库存提升到 20。完成引导后，还有若干进阶目标，会在你接触对应系统时逐步解锁，带你熟悉科研、物流与灾变机制。之后可以随时在「设置 → 关于」中重新查看全部引导内容。

开局推荐按以下顺序展开：

1. 电力优先。先建造 2 座太阳能板，保证后续设施有电可用。
2. 随后建造 2 座废料场，开始产出废钢。资源来自采集设施，能源设施本身不产出任何资源，这是新手最容易犯的错误。
3. 观察资源条。左侧是当前库存，右侧是每秒净变化。净变化为 0，通常表示产出已被下游设施全部消耗，或者设施因缺电被压低了产出。
4. 建造失误时，点击对应格子，在右侧详情面板中选择「拆除」，可以返还 35% 的建造材料。

如果某项资源长时间没有增长，可以按以下顺序排查：是否缺少采集设施；电力是否充足；下游设施是否缺少原料；设施是否仍在建造中。以上全部正常时，地图状态条会显示网络运行正常。生物质长期为 0 不一定是异常，当化工厂消耗掉生物质反应设施的全部产出时，净变化即为 0。资源条会分别列出总产出与总消耗，可以据此判断瓶颈出在哪个环节。

## 操作

- 在左侧选择蓝图，点击地图上的空位即可建造。大型设施按 2×2、3×3 或 5×5 整块占地，越出边界或与已有设施重叠时会给出提示。
- 点击已建成的设施可以升级。升级后产出提升至 1.6 倍，灾变受损风险同步上升，具体风险系数写在设施详情里。
- 在地图区按住 Ctrl 滚动滚轮可以缩放视角，以光标所在格子为锚点。触屏设备使用双指捏合缩放，设置面板中的 1× / 2× / 3× 按钮作为备用方式。
- 地图右侧的 ▲ / ▼ 用于切换地下层。顶栏提供科研、网络、终局与设置入口；移动端通过底栏在建造、地图、科研、物流与日志之间切换。
- 存档支持导出为带日期的文件、拖拽导入，以及 Base64 文本导入。导入前会先显示存档摘要并自动备份当前进度，确认后才覆盖。
- 鼠标拖动地图可以平移视角，位移超过 4 像素不会触发误建造。按 `R`、`Ctrl + 0` 或地图工具栏的 `⌖` 按钮，可将视角复原到居中并恢复 100% 缩放。
- 选中蓝图后，悬停在格子上会显示整块占地预览：可建造时显示为青色并叠加半透明幽灵，不可建造时显示为红色。
- 关闭页面后游戏完全暂停：不产出资源、不推进天数、不触发灾变。

## 核心规则

- 缺电时全图按比例降产，而不是直接停摆。效率等于供给除以需求；连续缺电 30 秒后，能耗最高的设施会被优先停机。
- 1 个游戏日为 90 秒（1× 速度），100 天约 150 分钟。
- 每张地图拥有独立的电网、库存、灾变压力与中转站。跨地图运输资源只能依靠商路。
- 商路具有容量、延迟与损耗，可能被脉冲切断，切断后需要付费重连。
- 日冕脉冲会提前一天预警，对没有抗性的设施造成相当于最大耐久 50% 至 70% 的伤害。同一格位反复受损会积累格位抗性，研究加固工程可以进一步减免。地下化设施免疫脉冲，但产出降至 70%。
- 灰烬风暴每 180 至 300 秒出现一次，持续 20 至 30 秒。期间全图产出减半，屏幕边缘会出现灰烬粒子。
- 设施必须连通网络才能运转。网络源包括灰烬平原的运算中心、其他地图的中转站、地下层的竖井升降机以及轨道层的空间站。断开的设施转入待机，不耗电也不产出。点击地图状态条可以直接定位到第一个出现问题的设施。
- 发射流程为：发射台 → 火箭装配厂 → 结构装配 → 燃料加注 → 发射 → 月背着陆 → 数据核心建城。
- 游戏共有三个结局：备份文明、留下（第 100 天开放）、上传（需要研发意识上传科技）。通关后可开启新周目+，保留科技与运算中心等级。

## 地下与大型设施

- 钻探炸药放置 10 秒后引爆，向下打通一层，并以爆破点为中心开放 3×3 空间。
- 地下支撑可以把相邻岩层转化为可建造的地基。地下层最多 3 层。
- 地下没有日照，也没有风暴：太阳能板与风力机不发电，采集类产出提升至 1.5 倍。
- 地下会随机发生塌方，把一格变回岩层并掩埋其上的设施。
- 发射台与火箭装配厂占地 5×5，轨道电梯与燃料厂占地 3×3，装配厂、芯片厂与数据核心占地 2×2。这些大型设施在计算相邻加成与受到伤害时，整块占地视为一个整体。
- 达成成就时，对应的名言会写入值守日志并弹出提示卡片。完整成就可以点击顶栏的「成就」查看。

### 镜面防御罩

- 建造成本为金属 120、芯片 30、稀土 40，耐久 120，需要先研究加固工程科技。
- 为周围 8 格（含对角）提供每座 6% 的脉冲伤害减免，单格减免上限为 45%。防御罩自身不享受减免。
- 防御罩必须连通且供电才能生效，待机或被限电时减免立即归零。
- 减免可与格位抗性、加固工程叠加，总减免不超过 90%。它抵不过升级带来的指数级风险，定位是保护关键节点。
- 选中防御罩时，界面会标出它覆盖的 8 格范围。

## 存档说明

主存档保存在浏览器 `localStorage`，每 10 秒自动写入。存档页支持导出文件（文件名带日期）、拖拽导入和 Base64 文本。导入前会展示周目、天数、设施数、科技数与保存时间；确认覆盖前会先把当前进度写成带时间戳的本地备份，必要时可恢复上一份。

存档格式为 v3，旧档自动迁移：v1 补齐地下层与尺寸字段；v3 之前的按天存储的脉冲日程按 `× 2/3` 折算（60 秒/天 → 90 秒/天）；迁移时记录统计起点，避免老档误发「全程型」隐藏成就。

「重新开始」会清除当前周目、地图、科技和主存档，需要二次确认，且不会保留新周目+的科技。
