# 百日之城 · Hundred-Day City

简体中文 | [English](README.en.md)

一款像素风基地建造与多地图物流增量游戏。建造设施、铺设商路，在一百天内把文明备份送往月背。

在线试玩：https://bio-innovator.github.io/Hundred-Day_City/

## 背景

太阳风暴之后，地表文明在三十年内崩塌。你是唯一仍在运行的 AI 运算中心，被遗留在一座灰烬平原的地下机房里，唯一指令是「保存文明」。

你没有手脚，只能通过建造设施、铺设商路，把散落在废墟里的资源重新连成一张网。一百天后，日冕脉冲会再次扫过地表——在那之前，你必须把文明备份送抵月背。


## 操作

- 在左侧选择蓝图，点击地图上的空位即可建造。
- 点击已建成的设施可以升级。
- 在地图区按住 Ctrl 滚动滚轮可以缩放视角，设置面板中的 1× / 2× / 3× 按钮作为备用方式。
- 鼠标拖动地图可以平移视角。
- 关闭页面后游戏完全暂停。

### 快捷键

| 键 | 作用 |
|---|---|
| `Space` | 暂停 / 继续（弹窗打开时不生效） |
| `1` / `2` / `4` | 切换流速 |
| `B` | 开/关建造面板 |
| `R` / `Ctrl + 0` | 复原视角 |
| `Esc` | 关闭弹窗 |
| `?` / `H` | 快捷键与操作说明 |

## 核心规则

- 缺电时全图按比例降产，而不是直接停摆。效率等于供给除以需求；连续缺电 30 秒后，能耗最高的设施会被优先停机。
- 1 个游戏日为 90 秒（1× 速度），100 天约 150 分钟。
- 每张地图拥有独立的电网、库存、灾变压力与中转站。跨地图运输资源只能依靠商路。
- 商路具有容量、延迟与损耗，可能被脉冲切断，切断后需要付费重连。
- 日冕脉冲会提前一天预警，对没有抗性的设施造成相当于最大耐久 50% 至 70% 的伤害。同一格位反复受损会积累格位抗性，研究加固工程可以进一步减免。地下化设施免疫脉冲，但产出降至 70%。
- 灰烬风暴每 180 至 300 秒出现一次，持续 20 至 30 秒。期间全图产出减半，屏幕边缘会出现灰烬粒子。
- 设施必须连通网络才能运转。网络源包括灰烬平原的运算中心、其他地图的中转站、地下层的竖井升降机以及轨道层的空间站。断开的设施转入待机，不耗电也不产出。点击地图状态条可以直接定位到第一个出现问题的设施。
- 发射流程为：发射台 → 火箭装配厂 → 结构装配 → 燃料加注 → 发射 → 月背着陆 → 数据核心建城。
- 游戏共有三个结局：备份文明、留下（第 100 天开放）、上传（需要研发意识上传科技）。通关后可开启新周目+，保留科技与运算中心等级。

## 存档说明

主存档保存在浏览器 `localStorage`，每 10 秒自动写入。存档页支持导出文件（文件名带日期）、拖拽导入和 Base64 文本。导入前会展示周目、天数、设施数、科技数与保存时间；确认覆盖前会先把当前进度写成带时间戳的本地备份，必要时可恢复上一份。

「重新开始」会清除当前周目、地图、科技和主存档，需要二次确认，且不会保留新周目+的科技。
