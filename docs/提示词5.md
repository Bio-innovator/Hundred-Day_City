**5.2 弹窗系统**（`hud.js:457-484`、`style.css:404-430`）

四条根因，逐条修：

| 根因 | 修法 |

### 第 2 批：节奏与手感（P1）

**5.3 一天 60 → 90 秒**（`maps.js:3`）

```js
export const DAY_SECONDS = 90;
```

**必须同时做两件事**，否则会出新问题：

1. **旧档迁移**：`nextPulseDay`、`lastWarningDay` 是按天存的，改天长度后要按 `× 2/3` 取整缩放，否则"下一次脉冲"会凭空延后 1.5 倍。

```js
nextPulseDay = Math.max(state.day + 1, Math.round(nextPulseDay * 60 / 90));
lastWarningDay = Math.round(lastWarningDay * 60 / 90);
```

2. **按秒计时的灾变要换算**：`balance.js:8-10` 的 `stormInterval: [180, 300]` 是秒，90 秒/天后会从"3–5 天一次"变成"2–3.3 天一次"。
   **推荐改成按天配置**（`stormIntervalDays: [3, 5]`），运行时 `× DAY_SECONDS`；至少也要整体 ×1.5。
   `disaster.js` 里陨石的 45 秒、轨道的 75 秒同样按比例处理。

**5.4 暂停外置**（`index.html:25-31`、`hud.js:259-264`、`hud.js:560`）

- 顶栏常驻「⏸ / ▶」按钮，`aria-pressed` 表示暂停态；暂停时顶部加 2px 色带
- **删除设置页里那个暂停按钮**，避免两处状态不同步
- `togglePause()` 现在只 `querySelector("#settings-pause")`，必须改成统一刷新：

```js
syncPauseUI() {
  document.querySelectorAll("[data-pause]").forEach((btn) => {
    btn.textContent = state.settings.paused ? "▶" : "⏸";
    btn.setAttribute("aria-pressed", String(state.settings.paused));
  });
  document.body.classList.toggle("paused", state.settings.paused);
}
```

- 暂停时画布加 8% 灰罩 + 「已暂停」角标（不要用模糊）

**5.5 快捷键**（`hud.js:229-236`）

现有：空格暂停、`B` 键。要补：

| 键 | 作用 |
|----|------|
| `Space` | 暂停/继续（保留，修冲突） |
| `1` / `2` / `4` | 调速 |
| `B` | 建造面板 |
| `R` / `Ctrl+0` | 视角复原 |
| `Esc` | 关弹窗 / 取消选中 / 退出建造 |
| `?` 或 `H` | 快捷键说明 |

- 输入框内不拦截（现有 `activeElement` 判断保留）
- **弹窗打开时只保留 Esc**，空格不再切换暂停
- 每个按键处理都 `preventDefault()`，避免空格滚页

### 第 4 批：玩法核心（P0）

**5.9 连通待机**（`state.js:120`、`production.js`）

**规则**：从网络源出发，沿上下左右 BFS，只穿过 operational 建筑与已解锁格；不可达 → `standby`。

- 源：灰烬平原 = 运算中心；其它地图 = 中转站；地下 = 竖井升降机/信标
- 新解锁且尚无中转站的地图：自动落一座**不可拆除的信标**作为临时源
- **待机效果：产出归零、能耗不计入需求、维修与加成不生效、外观变暗**
- 只在建筑集合变化时重算，缓存 `map.connectivity`，**不要每 tick 跑 BFS**
- `connected` 不持久化，加载后重算
- 选中显示「待机 · 未接入网络」；`diagnose.js` 增加「N 座未接入网络」
- 教程补一步："设施必须与运算中心连成一片才会运转"

**5.10 新建筑「镜面防御罩」**（`buildings.js` 参照 `fortification`）

| id | `mirrorShield` |
